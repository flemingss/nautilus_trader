# Roadmap

**This repository's working roadmap is
[`copilot/docs/ROADMAP.md`](copilot/docs/ROADMAP.md).** It is the central record of what
is built, what is open, and what unblocks each open item.

This file previously carried upstream NautilusTrader's roadmap. The repository was
detached from the fork network on 2026-09-01
([ADR-0010](copilot/docs/decisions/0010-the-repository-is-ours.md)), and upstream's
priorities are not a plan for this codebase - keeping them here made the wrong document
answer "what is this project doing next". The original remains readable at
[nautechsystems/nautilus_trader](https://github.com/nautechsystems/nautilus_trader/blob/develop/ROADMAP.md)
for deciding what is worth harvesting.
