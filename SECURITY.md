# Security

This repository is privately operated and takes no external vulnerability reports. A
defect here is ours to find and fix
([ADR-0010](copilot/docs/decisions/0010-the-repository-is-ours.md)); supply-chain
ownership - images, dependencies, CVE response - is recorded in
[`copilot/docs/MAINTENANCE.md`](copilot/docs/MAINTENANCE.md).

The inherited security policy, including the release-verification commands some inherited
documents still reference, belongs to upstream NautilusTrader and remains readable at
[nautechsystems/nautilus_trader/SECURITY.md](https://github.com/nautechsystems/nautilus_trader/blob/develop/SECURITY.md).
