# Contributing

**This repository does not take contributions.** It is privately operated: it began as a
copy of NautilusTrader and was detached from the fork network on 2026-09-01
([ADR-0010](copilot/docs/decisions/0010-the-repository-is-ours.md)). No change here is a
contribution to NautilusTrader, and there is no pull-request relationship with any other
project.

Work in this repository is governed by:

- [`copilot/docs/CHARTER.md`](copilot/docs/CHARTER.md) - the entry point, and the process
  the project is run by.
- [`AGENTS.md`](AGENTS.md) - working rules, including how inherited code is changed and
  registered.
- [`docs/developer_guide/coding_standards.md`](docs/developer_guide/coding_standards.md) -
  the inherited coding standards, kept because they are good.

This file previously carried upstream's contribution process - CLA signing, commit
conventions, and maintainer review. That process belongs to
[nautechsystems/nautilus_trader](https://github.com/nautechsystems/nautilus_trader) and
applies to work submitted there, not to work here.
