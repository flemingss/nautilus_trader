# Playbook

How the work is actually done. [`../CHARTER.md`](../CHARTER.md) says what we are trying to
achieve and which gate a candidate stands at; these four say how to get through them.

| Document | When you need it |
| --- | --- |
| [`PREFLIGHT.md`](PREFLIGHT.md) | Once, before any broker work. Account, permissions, market data, currency, tax, records |
| [`RESEARCH.md`](RESEARCH.md) | Every experiment. Discipline, partitions, gates, the frozen package |
| [`RISK.md`](RISK.md) | Sizing a position, setting a limit, or asking whether a premise survives at this account |
| [`OPERATIONS.md`](OPERATIONS.md) | Running a session, and every way one can go wrong |

Each carries its own checklist at the end, next to the process it belongs to rather than
collected somewhere they would be read out of context.
